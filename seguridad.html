Seguridad

Servidor FTP vsftpd y permisos

Responsable: Brandom Gamaliel Sánchez Guevara · SMSS017424

El servidor FTP del equipo es vsftpd. Cada integrante tiene su propia cuenta y solo puede escribir en /var/www/html/pupuseria. Todo se aplica con seguridad.sh.

1. Instalación

sudo apt install -y vsftpd
sudo cp /etc/vsftpd.conf /etc/vsftpd.conf.original
sudo nano /etc/vsftpd.conf

2. Parámetros de /etc/vsftpd.conf

ParámetroPara qué
anonymous_enable=NONadie entra sin cuenta
local_enable=YESEntran las cuentas del sistema
write_enable=YESPermite subir archivos
local_umask=022Archivos subidos quedan 644
ftpd_banner=Bienvenido al servidor FTP de Software LibreMensaje al conectarse
chroot_local_user=YESEncierra a cada usuario en su carpeta
chroot_list_enable=YES
chroot_list_file=/etc/vsftpd.chroot_list		Excepciones: el equipo llega a /var/www/html
userlist_enable=YES
userlist_deny=NO		Solo las cuentas de /etc/vsftpd.userlist pueden entrar

3. Cuentas individuales

sudo groupadd webequipo
sudo useradd -m -s /bin/bash -G webequipo despliegue
sudo passwd despliegue
# igual para: seguridad, desarrollo, basedatos, calidad
printf "despliegue\nseguridad\ndesarrollo\nbasedatos\ncalidad\n" | sudo tee /etc/vsftpd.chroot_list /etc/vsftpd.userlist

4. Permisos en /var/www/html

sudo chown -R root:webequipo /var/www/html/pupuseria
sudo find /var/www/html/pupuseria -type d -exec chmod 2775 {} \;
sudo find /var/www/html/pupuseria -type f -exec chmod 664 {} \;
sudo systemctl restart vsftpd
sudo systemctl status vsftpd

/var/www/html sigue siendo de root: el equipo solo escribe en la carpeta del caso. Las cuentas FTP no reciben sudo (mínimo privilegio).

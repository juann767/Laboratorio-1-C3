Seguridad

Servidor FTP vsftpd y permisos

Responsable: Brandom Gamaliel Sánchez Guevara · SMSS017424

El servidor FTP del equipo es vsftpd 3.0.5 en la máquina SoftwareLibreWalter (IP 192.168.74.128). Solo entran cuentas locales, sin acceso anónimo, y las cuentas de la lista de excepciones pueden llegar a /var/www/html.

1. Instalación de vsftpd

walter@SoftwareLibreWalter:~$ sudo apt install vsftpd
Installing:
  vsftpd
Summary:
  Upgrading: 0, Installing: 1, Removing: 0, Not Upgrading: 61
Des:1 http://deb.debian.org/debian trixie/main amd64 vsftpd amd64 3.0.5-0.2 [144 kB]
Configurando vsftpd (3.0.5-0.2) ...
Created symlink '/etc/systemd/system/multi-user.target.wants/vsftpd.service' → '/usr/lib/systemd/system/vsftpd.service'.

2. Configuración de /etc/vsftpd.conf

walter@SoftwareLibreWalter:~$ sudo nano /etc/vsftpd.conf

listen=NO
listen_ipv6=YES
anonymous_enable=NO
local_enable=YES
write_enable=YES
local_umask=022
dirmessage_enable=YES
ftpd_banner=Bienvenido al servidor FTP de Software Libre.
chroot_local_user=YES
chroot_list_enable=YES
chroot_list_file=/etc/vsftpd.chroot_list
ParámetroPara qué
anonymous_enable=NONadie entra sin cuenta
local_enable=YESEntran las cuentas del sistema
write_enable=YESPermite subir archivos
local_umask=022Archivos subidos quedan con permisos 644
ftpd_bannerMensaje de bienvenida al iniciar sesión
chroot_local_user=YESLimita a cada usuario a su carpeta personal
chroot_list_enable / chroot_list_fileUsuarios de la lista no quedan limitados y pueden llegar a /var/www/html

3. Lista de excepciones

walter@SoftwareLibreWalter:~$ sudo nano /etc/vsftpd.chroot_list

walter
usuario1

4. Privilegios y permisos sobre /var/www/html

walter@SoftwareLibreWalter:~$ sudo usermod -aG sudo walter
walter@SoftwareLibreWalter:~$ sudo chown walter /var/www/html
walter@SoftwareLibreWalter:~$ sudo service vsftpd restart
walter@SoftwareLibreWalter:~$ sudo service vsftpd status
